# 服务器迁移方案归档

本项目的迁移已于 2026-10-24 完成并验收。当前正式域名为 `https://mixiong6.com`，后续开发、数据库维护和发布均面向现役生产环境。本文件归档原迁移方案，避免后续维护误把历史步骤当作待执行任务。

## 验收摘要

- 57 张应用表、17,003 行数据逐表核对一致，外键检查通过。
- API、管理后台、数据库和 HTTPS 入口完成健康检查。
- 用户确认已发布使用 `mixiong6.com` 的小程序版本。
- 现行备份、部署和日常检查规则以 [`快速增量发布`](fast-deployment.md)、[`项目交接与开发避坑指南`](project-handover-and-engineering-guide.md) 为准。

## 可复用的迁移原则

1. 先盘点代码、环境变量、持久化卷、数据库、域名证书、定时任务和第三方白名单。
2. 在迁移前验证数据库备份可恢复，并保留离线副本。
3. 数据量较大时可先复制静态资源和基础数据；最终切换前暂停所有写入，再复制最后增量并完成对账。
4. 对账须覆盖每张业务表，至少核对行数、主键和字段摘要；同时确认结构迁移、外键与关键业务查询。
5. 新环境测试时隔离会写数据或向真实用户发通知的后台任务，避免重复同步、重复通知。
6. 切换前后都检查 HTTPS、API 健康状态、登录、关键页面、POS 同步及小程序请求；确认由用户决定的小程序审核/发布步骤已经完成。
7. 有新写入后不能只回退 DNS；必须先明确数据库如何回切，避免丢失切换后的业务数据。
8. 服务器地址、SSH 用户、密钥和生产环境变量留在受控的本机/密码管理器中，不写入 Git 仓库、截图或命令历史。
