# 2.1.74 发布记录（2026-10-22）

## 本轮内容

- 修复部分微信/鸿蒙运行环境把排班时间显示为 `GMT+0800 (CST)` 的问题。原因是这些运行环境没有一致执行 `toLocaleTimeString` 的语言和时区选项；小程序改为按接口时间戳显式换算中国时区并输出 `HH:mm`。本人排班、门店排班、工时确认、更正和排班汇总图片统一使用该格式。
- 增加门店排班点位设置；批量排班按员工选择点位，支持同一员工多个不冲突班次，汇总图在员工姓名后显示点位及班次时间。排班颜色按员工区分。
- 员工岗位可复用到多个门店，并按门店设置时薪；员工资料编辑仍按对应人事权限控制。
- 岗位选择接口同时校验员工编辑与门店入职核验权限。
