## 页面布局

- 首页保留门店今日销售、入客和客单价，并将“每日填报、经营日报、历史日报、填报提醒”放入四列图标区。“人事工作台”是独立的图标卡片。
- 人事工作台分“我的工作”和“门店事务”两组：个人可查看排班与工时；门店管理功能按当前账号的人事权限显示明日排班、昨日工时、工时更正、员工转店。
- 只有拥有多个授权门店时才显示切换门店；单门店账号直接显示本店名称。
- 所有模块使用本地 SVG 图标，操作按钮和卡片保持统一触控面积。实际数据仍由原 API 获取，权限仍由服务端判定。
- 未登录时首页展示明确的登录入口；经营数据读取失败时显示错误和重试入口，不阻断已登录用户进入人事工作台。
