# 2.1.80 发布记录（2026-10-24）

## 本次更新

- 员工列表增加账号关联设置，可搜索并关联已存在的同门店账号；关联会检查账号归属和重复绑定，不会更改账号角色或门店权限，并写入审计记录。
- 日报提交先保存为已提交，再尝试同步 POS。POS 同步异常不再把日报退回草稿或返回 503；系统后台每 5 分钟重试，最多 6 次，并对重复提交保持幂等。
- 经营数据权限拆为首页经营数据、当日经营日报、历史经营日报、填报提醒等独立权限；当日/历史日报和提醒接口均校验门店权限。
- 消息设置和首次授权按当前账号权限及实际流程过滤：无对应权限或无本人已发布排班的账号，不显示相关开关，也不会弹出无关授权；已发布班次再次修改时，站内消息显示“排班调整通知”。

## 验证与发布

- 自动测试：193 项通过（经营报表、HR 引擎、API、后台日期逻辑）。
- TypeScript API 构建、后台生产构建、微信小程序构建均通过。
- 后台 API 已增量发布到当时的正式环境；API 健康检查正常，API、后台、Caddy、MySQL 容器均运行。`https://mixiong6.com/` 返回 HTTP 200；新账号关联 API 路由已部署并由认证层正确拦截未登录请求。
- 微信小程序 **2.1.80（versionCode 289）** 已上传为开发版，包体 553,898 字节；未提交审核、未发布线上，审核及正式发布由产品负责人手动完成。

## 权限配置提醒

新增权限在后台“人事管理 → 角色管理 → 经营数据”分组。管理员需要按需给现有角色勾选“查看当日经营日报”“查看历史经营日报”“查看和处理填报提醒”，对应账号才会显示这些功能；填报权限继续使用已有的“提交门店经营日报”。
