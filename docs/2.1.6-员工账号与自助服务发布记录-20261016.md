# 2.1.6 员工账号与自助服务发布记录（2026-10-16）

## 已完成

- 入职审批完成且到达申请生效日后，在生效事务内创建或关联手机号账号，并绑定 HR 员工档案。
- 新建账号使用微信手机号快捷登录，默认员工级账号，不写入 `UserStore`，不自动获得经营数据或门店填报权限。
- 员工本人可在小程序人事工作台查看本人已发布排班、已确认工时和个人资料。资料访问写入审计日志，银行卡号只显示后四位掩码。
- 新增独立权限 `HR_DAILY_INPUT_WRITE`。总部可以在人事角色权限中选择该能力，并按门店/区域授权；员工提交日报时还需匹配填报日期生效的在职门店。
- 新账号没有该权限时，填报 API 拒绝读取/保存/提交；未关联 HR 员工的原有日报账号继续使用已有门店授权规则。
- 小程序每日填报页支持由 HR 工作台传入授权门店，员工账号不会展示顺位/转派提醒控件。

## 手机号冲突处理

- 已有启用账号且尚未关联其他 HR 员工：沿用该账号并关联员工档案，不改其密码、微信绑定或角色。
- 手机号账号已停用，或已绑定其他员工：入职请求标记 `EFFECTIVE_FAILED`，不会复活账号或抢占账号。
- 新建员工账号采用 `STORE_MANAGER` 的兼容角色值，但不创建 `UserStore` 关联；小程序个人页按无经营门店账号显示“员工”。
