# 人事 2.1 OCR 接入决定

2026-10-14，产品负责人指定阿里云为身份证 OCR 服务商。采用阿里云文字识别的 `RecognizeIdcard`，只把识别结果作为入职资料的预填建议，必须人工校对、确认后才能进入审核。

现有 `apps/api/src/hr/aliyun-idcard-ocr.provider.ts` 已适配身份证正反面结构化字段、字段置信度和阿里云请求号；限制 JPEG/PNG、10 MB。官方接口支持的主要字段是姓名、性别、民族、出生日期、地址、身份证号、签发机关和有效期限。已安装官方 `@alicloud/ocr-api20210707` SDK，适配 SDK 的 `body.data` 响应，并通过二进制流构造 `RecognizeIdcardRequest`。AccessKey 配置迁到总部后台“人事管理 → OCR 识别配置”，用专用 `HR_OCR_CREDENTIAL_ENCRYPTION_KEY` AES-256-GCM 加密保存；读取接口只回传是否已配置、启停状态和最后更新时间。数据库密文不写日志，访问与启停均写审计。数据库中的启用状态默认关闭；完成 AccessKey 配置后还需总部管理员显式启用。当前实际 AccessKey 仍未配置，因此没有真实云端调用或生产采集。

正式启用前需完成：开通阿里云个人证照识别服务，为专用 RAM 身份授予 `ocr:RecognizeIdcard` 最小权限；密钥只放服务器密钥管理或运行环境，不能进入仓库或小程序；实现受控上传和短期加密存储、内容检测、访问审计、处理依据与留存/删除政策；以脱敏样本完成云端到端测试。图片以二进制传给 SDK，不创建公开图片 URL。OCR 返回值不直接写入已审核员工资料。结构化身份证号、银行卡号的 AES-256-GCM 封装已在 `apps/api/src/hr/hr-sensitive-crypto.ts` 完成并通过本地测试，仍未接入数据库和生产密钥管理。

官方接口：[RecognizeIdcard 文档](https://help.aliyun.com/zh/ocr/developer-reference/api-ocr-api-2021-07-07-recognizeidcard)；[接入点](https://help.aliyun.com/zh/ocr/developer-reference/api-ocr-api-2021-07-07-endpoint)。
