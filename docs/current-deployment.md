## 已确认的入客数口径

- 入客数取 POS 菜品明细中 `sales_revenue_type_id=2052593114365374465`（计算碗数）的销售数量。
- 套餐父项不计数，套餐内品项展开后按同一规则计算；菜品名称包含“半份”时按 0.5 碗计算。
- 全天先汇总小数再四舍五入。堂食/外卖及午餐/晚餐采用最大余数分配整数，保证各分项之和等于全天人数。
- 结算明细中含“员工餐”的订单不计入入客数和时段人数；销售额、菜品销量保持 POS 原始值。
- 2026-09-27 山西大学店按当前口径为总入客 368、堂食 190、外卖 178、午餐 263、晚餐 105。

## 菜品分类口径

- 菜品不做人工映射，以 POS API 返回的商品小类为准；小类缺失时使用大类。
- 每次主数据同步都会刷新商品所属分类，后台不能修改 POS 商品的分类。
- 人工用电、用水、工时与运营人数未填报，相关指标会显示空值。
