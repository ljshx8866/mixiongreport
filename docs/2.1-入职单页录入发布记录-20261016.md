# 人事入职单页录入发布记录

发布时间：2026-10-16（北京时间）

## 本次交付

- 入职页面改为单页直接录入和提交，不再要求门店先创建员工草稿、再分步保存证件和银行卡资料。
- 增加手机号、住址字段；姓名、身份证信息、银行卡信息和生效日期均在同一表单核验。
- 身份证照片选择后在表单页面预览；OCR 识别出的姓名、证件号码、性别、民族、出生日期和地址完整填入可编辑字段。
- 照片只在本次识别请求中使用，不保存原图。身份证、手机号、地址和银行卡结构化数据仍按员工和用途加密保存；审批列表继续显示脱敏号码。
- 后端在一个可串行化事务中创建员工记录、加密资料版本、身份证唯一认领、入职申请和审批快照；失败时整笔回滚。
- 直接提交要求账号同时具备员工录入、敏感资料录入和门店原件核验权限。
